# Sqlthon

A powerful, Pythonic layer for SQLite3 — built for developers who don't know SQL.

## Why Sqlthon?

SQLite is powerful, but using it requires knowing SQL. Sqlthon lets you work with SQLite databases using **pure Python objects and methods** — no SQL queries needed. Just define your tables and fields, and Sqlthon handles the rest.

**Sqlthon is:**
- ✅ A powerful layer for working with SQLite3 in pure Python
- ✅ Built for developers who don't know SQL
- ✅ Suitable for real projects and production use

**Sqlthon is NOT:**
- ❌ A replacement for the built-in `sqlite3` module
- ❌ A toy package for tiny scripts
- ❌ Feature-complete yet — it's under active development
